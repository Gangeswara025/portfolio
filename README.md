## 📖 Overview

This portfolio is not a traditional developer portfolio.

It is designed as an immersive cinematic internet experience inspired by:

* Cyberpunk aesthetics
* AI command centers
* Futuristic holographic systems
* Interactive WebGL environments
* Awwwards-level cinematic websites

The experience combines storytelling, motion design, 3D interactions, and modern frontend engineering to create a memorable recruiter-facing portfolio.

## 🧠 Design Philosophy

The goal of this project was to move beyond generic portfolio templates and create something that feels alive, cinematic, and immersive.

The website focuses heavily on:

* Atmosphere
* Motion hierarchy
* Cinematic composition
* Story-driven interaction
* Premium internet aesthetics

Instead of stacked sections and simple cards, the portfolio creates the feeling of navigating through a futuristic AI command system.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/gangeswara-portfolio.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
